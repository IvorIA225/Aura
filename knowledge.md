## ❓ FAQ

### Comment modifier ma commande ?
- Si la commande n'est pas encore expédiée, contacter le service client rapidement
- Une fois expédiée, la commande ne peut plus être modifiée

### Comment annuler ma commande ?
- Annulation possible tant que la commande n'est pas expédiée
- Contacter le service client avec le numéro de commande
- **⚠️ Escalader vers un humain pour toute annulation**

### Mon colis est endommagé, que faire ?
- Prendre des photos du colis et du produit endommagé
- Contacter le service client avec les photos et le numéro de commande
- Un remplacement ou remboursement sera proposé sous 48h

### Je n'ai pas reçu mon colis
- Vérifier le suivi de commande d'abord
- Si le suivi indique "livré" mais non reçu : vérifier auprès des voisins/gardien
- Si toujours introuvable : contacter le service client pour ouvrir une enquête

### Comment utiliser un code promo ?
- Entrer le code dans le champ "Code promo" au moment du paiement
- Un seul code promo par commande
- Les codes ne sont pas cumulables avec d'autres offres sauf mention contraire
